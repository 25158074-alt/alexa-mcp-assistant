# Daily Briefing

Use this skill to turn user-provided reminders, calendar items, or priorities into a short spoken briefing.

## Rules

- Only summarize items supplied by the caller.
- Never invent calendar events, messages, weather, or personal data.
- Keep the result concise and easy to read aloud.
- Preserve the order of the supplied items.

## Input

- `greeting`: optional greeting.
- `items`: an array of strings.

## Output

Return the greeting, item count, and a short briefing.
