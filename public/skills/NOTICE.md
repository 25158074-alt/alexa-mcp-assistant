# Bundled Agent Skills attribution

The four MCP Extensions Agent Skill files in this directory were retrieved from the official `modelcontextprotocol/ext-apps` repository under `plugins/mcp-apps/skills/`. Their names and sources are linked from the Agent Skills view in the app.

The upstream repository's `LICENSE` file is included unchanged alongside these files. It describes a licensing transition and states that documentation contributions (excluding specifications) are licensed under CC-BY-4.0, while some contributions may remain under MIT absent relicensing consent. Consult the included license and original skill source files for the applicable terms and provenance.

Official repository: https://github.com/modelcontextprotocol/ext-apps
